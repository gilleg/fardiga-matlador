# fardiga-matlador.se

En svensk, fristående jämförelsesajt om färdiglagade matlådor med hemleverans. Sajten jämför tjänsternas upplägg, portionsriktmärken, kostinriktningar, leverans och praktiska villkor - inte bara en lockande startkostnad.

## Inriktning

- Helhetsval: Svarta Lådan
- Kostprofiler: Factor
- Näringsinformation och träning: Macro Meals
- Klassisk färdig vardagsmat: Färdiga Maten

Artiklarna skiljer färdiglagad mat från matkassar med råvaror och recept. Uppgifter om meny, pris, innehåll och leveransområde ska alltid kontrolleras på aktuell beställningssida före köp.

## Lokalt

```bash
npm install
npm run dev
npm test
```

## Källunderlag

- Svarta Lådans produkt- och leveransinformation
- Factors meny- och kostprofilinformation
- Macro Meals produkt- och näringsinformation
- Livsmedelsverket och Konsumentverket för generella råd om mat och konsumenträtt
